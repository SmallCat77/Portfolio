# Personal Portfolio

A personal portfolio website built with React and Vite to showcase my background, skills, and projects as an IT student.

## Features

- Responsive portfolio layout
- Hero, About, Projects, and Contact sections
- Dedicated profile page using React Router
- GSAP animations
- Dark theme with lime-green accents
- Project showcase featuring VaxCare, CarX, and Web Portfolio

## Tech Stack

- React
- Vite
- JavaScript
- HTML5 and CSS3
- React Router
- GSAP

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/SmallCat77/portfolio.git
   ```

2. Navigate to the project folder:

   ```bash
   cd portfolio
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL shown in your terminal, usually `http://localhost:5173`.
